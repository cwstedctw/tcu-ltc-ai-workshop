01・一個資料夾＝一個小隊

看得懂

AI 記不住的事，寫成檔案就記得住

為什麼要一個資料夾？AI 的記憶各家分開，換一個對話常常就忘了。寫在資料夾裡的規則和紙條，哪一家打開都讀得到。
對研究的好處：每一步都留下檔案，事後查得到 AI 做了什麼、你改了什麼。
你＝小隊長
出題目、看成果、做決定
→
領隊
想清楚、寫紙條、驗收
→
隊員
照紙條動手、交成品

這個小隊住在一個範本資料夾裡，叫 ai-team-starter。打開它，會看到：

檔案或資料夾做什麼
AGENTS.md小隊公約：誰是誰、怎麼傳紙條、三種模式、共同規則。Codex 讀這份。
CLAUDE.md只有一行 @AGENTS.md。Claude 讀這份，等於照同一份公約。
team.md這個小隊平常用哪一種模式。
roles/領隊和隊員的個性與原則，名字可以改。
material/你的材料，公約規定 AI 只讀、不寫。練習用/ 裡放了一份虛構的照顧者訪談，給今天練習；換成自己的材料前先移走。
workspace/inbox/領隊寫的紙條：做什麼、什麼格式、怎樣算做完。
workspace/outbox/隊員交的成品，-v1、-v2 每一版都留著。
workspace/log.md小隊紀錄：每一棒寫一行，領隊簽收也寫在這裡。
說得出領隊、隊員各做什麼，紙條和成品放在哪裡。
02・三步建好

拿得到

用範本建自己的私人儲存庫，抓到電腦上打開

  1. 2-1用範本建自己的私人儲存庫

    方法一：在網頁上按。打開範本頁 github.com/cwstedctw/ai-team-starter，按 Use this template → Create a new repository。名字填 my-research-team，下面的公開範圍一定要點成 Private（預設可能是 Public），再按 Create repository。

    方法二：請 AI 助手代勞。行前第 10 項裝好 gh、登入過的人，在 AI 助手（第 6 項打開 AI-workshop 的那個）貼：

    請用 gh 從範本 cwstedctw/ai-team-starter 建一個私人儲存庫，名字叫 my-research-team，並 clone 到目前這個 AI-workshop 資料夾裡。做完告訴我三件事：clone 下來的完整路徑、GitHub 網址、它是不是 Private。

    AI 要連上 GitHub，會先問你可不可以：看得到 my-research-team 和 --private 就按同意。Private 不等於可以放受試者資料，放之前先看範本裡的 material/README.md。

    完成判準：瀏覽器打開 github.com/你的帳號/my-research-team，名字旁邊寫著 Private。

  2. 2-2抓到電腦上

    用方法二的人已經抓好了，跳過這步。用方法一的人，在 AI 助手貼：

    請把我 GitHub 上的 my-research-team 儲存庫 clone 到目前這個 AI-workshop 資料夾裡，做完告訴我完整路徑。
    完成判準：AI-workshop 裡多了一個 my-research-team 資料夾，裡面看得到 AGENTS.md。

  3. 2-3在桌面版打開這個小隊

    Codex：按「開啟資料夾」（或意思一樣的按鈕），選 my-research-team。Claude 的 Code：環境選「本機（Local）」，再選 my-research-team。

    要選 my-research-team 本身，不是外面的 AI-workshop。AI 只讀打開那一層的 AGENTS.md，選錯層它就不知道自己在小隊裡。

    打開後先說一句：

    請先讀 AGENTS.md，再跟我報到。
    完成判準：它的第一行以「領隊 ·」開頭，印出的路徑結尾是 my-research-team；輸入框旁的權限選單還是 Ask for approval（Codex）或 Manual（Claude）。
做完勾一勾（3 項全勾，解鎖技能卡 02）
03・單人模式

跑得動

只有一家 AI，也能先做、再自己驗收

單人模式由同一個 AI 輪流戴兩頂帽子。它每換一次帽子，就在資料夾裡留一個檔：

  1. 領隊寫紙條放進 inbox：做什麼、什麼格式、怎樣算做完。
  2. 隊員做 v1存進 outbox，第一行寫交接。
  3. 領隊驗收：每一句對回 material 的原文；要改就寫退回紙條。
  4. 有退回才改 v2，另存新檔、v1 留著。最後向你回報。

貼這句試試（今天只用虛構的練習訪談）：

這次用單人模式。請把 material/練習用 裡的虛構訪談做初步編碼：列出 3 到 5 個主題，每個主題附一到兩句原文當證據，並標出你不確定的地方。

做的過程中，Claude（Manual）或 Codex 會跳出好幾次權限視窗：要在 workspace 裡建檔，按允許；看不懂的指令按拒絕也沒關係。不要選「以後都允許」或切換到自動模式的選項。

它說做完之後，自己打開這三個地方看：（.md 檔按兩下打不開的話：右鍵 → 開啟檔案 → 記事本；Mac：右鍵 → 打開方式 → 文字編輯）

  • workspace/inbox/ 的紙條：有沒有寫清楚「怎樣算做完」？
  • workspace/outbox/ 的成品：第一行有沒有交接？有退回紙條的話，v2 改了什麼？
  • 從成品複製兩句「原文證據」，打開 material/練習用/虛構訪談-X01.md，按 Ctrl＋F（Mac：Command＋F）貼上：找得到嗎？不要用手打，全形標點很容易打錯。

AI 說做完，不等於做完。主題怎麼定、證據夠不夠，最後還是研究團隊決定；AI 給的是可以檢查的初稿。

做完勾一勾（3 項全勾，解鎖技能卡 03）
04・兩家接力

接得上

兩家都有，就讓它們分工

先看你手上有什麼，下面會建議用哪一種模式，並給你 team.md 要填的內容。

ChatGPT（Codex）
Claude
兩家的命令列工具（codex、claude）都裝好、登入了嗎？

手動接力：每一棒由你傳

  • 兩個桌面版都打開 my-research-team。
  • 跟領隊說需求，它寫好紙條就停。
  • 到另一個桌面版說「你是隊員。看 inbox 最新的紙條，照著做。」
  • 隊員交進 outbox 就停；你回去跟領隊說「收 outbox」。

Claude 的 Code 要 Pro 以上。每一棒都經過你，每一步都看得見。

自動接力：領隊自己叫隊員（講師示範）

  • 你只跟領隊說話，它在資料夾裡執行另一家的命令列工具。
  • 每叫一次隊員，AI 助手會先問你可不可以；但你核准的只是「叫隊員」這一下，隊員在資料夾裡建檔、改檔不會再問你。所以開始前先存一版（commit），出事可以退回。
  • 紙條、每一版照樣留在資料夾裡。

要兩家的命令列工具都裝好、登入，今天由講師示範。

自動接力時，領隊會執行的指令（寫在 AGENTS.md 裡，不用自己打）：

領隊是 Claude、隊員是 Codex： codex exec --sandbox workspace-write "你是隊員。先讀 AGENTS.md 和 roles/member.md，再照 workspace/inbox 最新那張紙條做。" 領隊是 Codex、隊員是 Claude： claude -p --permission-mode acceptEdits "你是隊員。先讀 AGENTS.md 和 roles/member.md，再照 workspace/inbox 最新那張紙條做。"

領隊每一棒做四道檢查，因為指令「成功」不代表做對：

一

叫到的真的是隊員嗎？

隊員最後回覆的第一行要以「隊員 ·」開頭。看到「領隊 ·」，表示叫到第二個領隊，停下來告訴你。

二

outbox 真的多了新檔嗎？

指令正常結束，不等於做完。先看到新檔，才說隊員做好了。

三

指令還在跑嗎？

一棒可能要好幾分鐘。指令已經結束，就不能說「隊員還在跑」。叫不起來就改單人模式，不自己繞路。

四

不該動的檔有沒有被動？

用 git status 看：只該多出 workspace 裡的新檔。material、AGENTS.md、roles 有變動就停下來告訴你。

知道自己適合哪一種模式，也說得出四道檢查。
05・跨電腦與遙控

到處用

辦公室開始、家裡接著做、手機看進度

辦公室電腦⇄GitHub（Private）⇄家裡電腦筆電

規則只有一條：開工先拉、做完就推。在另一台電腦第一次用，就像 2-2 那樣 clone 一次。

開工時貼

開工前請先 git pull，告訴我從 GitHub 拿到了哪些新東西。

收工時貼

今天改了哪些檔案，請先列給我看，特別標出 material 裡新放的檔。我同意之後，再存一版並推上 GitHub。

人不在電腦前，也能用手機接著做。兩家都有遙控功能，AI 和檔案都留在原本那台電腦上，手機只是遙控器：

Claude（Code）ChatGPT（Codex）
電腦這邊在 Code 的對話裡輸入 /remote-control，或打開那段對話的 Remote Control 開關。設定 → Claude Code 裡的「Connect new sessions to Remote Control」打開後，新對話都會自動連上。用最新的 ChatGPT 桌面版（Mac 或 Windows）：設定 → Connections → Control this Mac or PC，用手機掃畫面上的 QR code。
手機這邊Claude app 的 Code 清單裡找到那段對話。ChatGPT app 打開 Codex（有些版本叫 Remote）。
可以做什麼看進度、接著下指令、回應權限提示。看進度、核准指令、開新的工作。核准時只選「這一次」。

電腦要開著、不能睡、要連網，登入同一個帳號。手機能叫 AI 做的事，就是那台電腦上的 AI 能做的事，所以授權要維持行前第 7 項選的「會先問」，手機上也只核准看得懂的。手機掉了，到網頁版的設定把所有裝置登出。字樣以你的畫面為準。

知道開工先拉、做完就推，也知道遙控時電腦要開著、只核准看得懂的。

第三部分會在這個小隊上，再加搜文獻、Zotero 書目和自動編譯論文的工具。
