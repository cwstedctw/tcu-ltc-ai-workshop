  1. 1先學一招：截圖問 AI卡住問網頁版

    後面每一項卡住，都靠「把畫面拿給 AI 看」解決。這一項先學會怎麼截、怎麼貼就好，不用真的送出；第 2 項註冊好帳號，就隨時能問。

    同時按住 Win 鍵（鍵盤左下角有四個小方塊圖案的那顆）和 Shift，再按一下 S。螢幕變暗後，按住滑鼠左鍵拉一個框，把卡住的地方框起來，放開就複製好了。再到 AI 打字的框裡按 Ctrl＋V 貼上。

    按 Control＋Command＋Shift＋4，游標變成十字後拉一個框，把卡住的地方框起來，放開就複製好了。再到 AI 打字的框裡按 Command＋V 貼上。

    只框出錯的那一小塊，不要框整個螢幕。截圖會整張送到 AI 的雲端。送出前看一眼圖裡有沒有姓名、病歷號、email、登入碼、QR code 或 LINE 通知；有就重截。有密碼、備援碼、學生或受試者資料的視窗，截圖前先關掉。

    截好圖，先把圖貼進 AI 的打字框，再複製下面這句貼在後面：

    第 8、9、10、12 項：交給 AI 助手做
    第 6 項在 Codex 或 Claude 的 Code 打開練習資料夾之後，它就能直接替你裝、替你做。AI 助手自己卡住（不回應、一直出錯），就截圖回網頁版問。

  2. 2ChatGPT：帳號＋桌面版＋找到 Codex卡住問網頁版

    先到 chatgpt.com 登入或註冊，記住用的是哪個帳號、用哪種方式登入（Google、Apple 或 email）。再到官方下載頁 chatgpt.com/download 下載桌面版，照畫面裝好，用同一個帳號、同一種方式登入，不然可能變成兩個帳號；登入後核對 email 一樣就對了。

    下載完找不到安裝檔：看瀏覽器右上角的下載清單（向下箭頭圖示），從那裡打開。

    Mac 需要 macOS 14 以上（蘋果選單 → 關於這台 Mac，可以看版本）。

    電腦裡原本就有舊版 ChatGPT 的話，新版可能會另外裝一個，舊版改名叫 ChatGPT Classic。兩個並存是正常的，開新的那個。

    打開桌面版，左上角的選單可以切換 ChatGPT 和 Codex。Codex 是 ChatGPT 裡會打開資料夾、動手做事的那一面。切到 Codex，看到可以打字的輸入框就好，先不用叫它做事。

    完成判準：在桌面版的 ChatGPT 隨便打一句話，再到網頁版重新整理，看得到那段對話；兩邊左下角頭像的 email 一樣；而且切得到 Codex。
    卡住怎麼問網頁版 AI
    我在裝 ChatGPT 桌面版，卡在＿＿（例如：登入被擋／裝好打不開／找不到 Codex），畫面如附圖。請告訴我畫面上發生什麼事，再一步一步帶我。我用的是＿＿（Windows／Mac）。

    貼上之後，把「＿＿」換成你的情況再送出。

  3. 3Claude：帳號＋桌面版卡住問網頁版

    先到 claude.ai 登入或註冊，一樣記住登入方式。再到官方下載頁 claude.com/download 下載桌面版，照畫面裝好，用同一個帳號、同一種方式登入。

    桌面版裡有「Code」（通常在畫面上方中間，和 Chat、Cowork 並排；舊版畫面可能在側邊欄），這是會打開電腦資料夾、動手做事的那一面。Code 要 Pro 以上的付費方案才能用，免費帳號點了會請你升級。這是正常的，先關掉，下一項再決定要不要付費。

    完成判準：在桌面版隨便打一句話，再到網頁版重新整理，看得到那段對話；兩邊左下角名字縮寫的 email 一樣。有付費的人，再確認點得開 Code。
    卡住怎麼問網頁版 AI
    我在裝 Claude 桌面版，卡在＿＿（例如：登入被擋／裝好打不開／點 Code 要我升級），畫面如附圖。請告訴我畫面上發生什麼事，再一步一步帶我。我用的是＿＿（Windows／Mac）。

    貼上之後，把「＿＿」換成你的情況再送出。

  4. 4決定要不要付費卡住問網頁版

    不付費也可以來上課。第一部分（兩家的設定）大部分免費也能做，少數功能要付費，當天的頁面會標出來；差別主要在第二部分：

    你的方案第二部分：AI 怎麼幫你做事
    兩家都免費只用 ChatGPT 的 Codex 從頭做到尾；免費的使用量（額度）較少，可能做到一半要停下來等
    只付 ChatGPT只用 Codex 從頭做到尾；額度比較多，比較不會做到一半停下來
    只付 Claude只用 Claude 的 Code 從頭做到尾
    兩家都付兩個 AI 接力，一個做、一個檢查

    價格以官方定價頁為準：ChatGPT 看 chatgpt.com/pricing，Claude 看 claude.com/pricing。只為這場訂的話，用完記得取消自動續訂。

  5. 5GitHub 帳號卡住問網頁版

    到 github.com 註冊一個帳號，記得回信箱按驗證信。註冊後如果跳出一整頁英文問卷，可以略過不填。已經有帳號的人，確認還登得進去就好。GitHub 是放資料夾備份、讓不同電腦拿到同一份的網站；記錄每一次修改的，是第 8 項的 git。

    登入時如果畫面要你設定兩步驟驗證，就照做：手機裝一個驗證 App（例如 Google Authenticator），掃網頁上的 QR code，再把備援碼存好。備援碼是手機不能用時的救援鑰匙，自己收好，不傳給 AI，也不傳給老師。沒被要求的人不用特地開。

    完成判準：登入後看得到自己的個人頁，網址是 github.com/你的帳號名。

  6. 6建一個練習資料夾，在 AI 助手裡打開卡住問網頁版

    後面幾項都要在 AI 助手裡做。它主要在你打開給它的那個資料夾裡工作；哪些動作會先問你，看第 7 項。選了資料夾，不代表其他檔案它都讀不到。所以先建一個空的練習資料夾：

    1. 打開檔案總管（工作列上黃色資料夾的圖示）。
    2. 左邊點「本機」，右邊連按兩下「D 槽」進去；沒有 D 槽就連按兩下「本機磁碟 (C:)」。
    3. 在空白處按滑鼠右鍵 →「新增」→「資料夾」，名字打 AI-workshop，按 Enter。

    建好的位置是 D:\AI-workshop 或 C:\AI-workshop。不要放桌面或「文件」，那裡常被 OneDrive 同步。建不了（跳出權限不足），就停在這一項求救。

    1. 打開 Finder，上方選單點「前往」→「個人專屬」（你的使用者資料夾，圖示是一棟小房子）。
    2. 上方選單點「檔案」→「新增檔案夾」，名字打 AI-workshop，按 Return。

    不要放桌面或「文件」，那裡常被 iCloud 同步。

    然後在 Codex 輸入框上方點「選擇專案」→「新專案」；來源資料夾按「新增」，選 AI-workshop、按「選擇資料夾」；專案名稱也打 AI-workshop，再按「建立專案」（英文介面字樣不同，位置一樣）。用 Claude 的 Code 時，先在環境選單選「本機（Local）」，再選這個資料夾。畫面要顯示這個資料夾的名字。

    不要選放有研究資料、受試者或學生資料的資料夾，AI 打得開的資料夾它就讀得到。這個練習資料夾只放假資料或公開資料。

    完成判準：AI 助手的畫面上顯示 AI-workshop。

  7. 7調一下 AI 助手的授權卡住問網頁版

    這一項決定 AI 動手前要不要先問你。後面幾項它會開始替你裝東西，所以先調好。

    • Codex：輸入框下方有一個手掌圖示的權限選單，選 要求核准（英文介面叫 Ask for approval）。在練習資料夾裡，它會直接建檔、改檔；要修改資料夾以外的檔案或上網，會先問你。不要選「完整存取權」（Full access），也先別選「代我核准」（Approve for me，由系統判斷要不要問）。
    • Claude 的 Code：輸入框下方的模式選單，選 Manual（手動）。新版可能一開始是「自動」（Auto）；不管現在顯示什麼，都改成 Manual。選 Manual 之後，改檔、跑指令前都會先問你；只是讀檔案不會問。不要選「自動」（由系統判斷要不要問）、「接受編輯」（Accept edits，改檔不問）和「略過權限確認」（Bypass permissions）。

    選單字樣以你電腦上看到的為準。凡是說明寫著「不問、不限制、整台電腦都能讀寫」的都不要選。

    完成判準：Codex 的權限選單顯示 要求核准（或 Ask for approval）；Claude 的模式選單顯示 Manual（或它的中文名稱）。找不到，先別往下做，截圖問網頁版，或回信問陳老師。

  8. 8裝 git交給 AI 助手做

    git 是替資料夾記住每一次修改的工具。在第 6 項打開的 AI 助手裡貼這句：

    請幫我確認這台電腦有沒有裝 git；沒有的話幫我裝好，Windows 用 winget 或 git-scm.com 官方網站，不要從其他網站下載。過程中要我做什麼，請一步一步告訴我。裝完如果找不到 git，先檢查安裝位置，不要反覆重裝。最後把版本號給我看。

    AI 要上網下載或執行安裝程式之前，會先在對話裡請你核准（第 7 項設的就是這個）。看得出是在裝 git 就同意；看不懂就先拒絕，截圖問網頁版。

    接著螢幕可能變暗，跳出「是否允許這個 App 變更你的裝置」。這是安裝的正常步驟：是你剛請 AI 裝東西時跳出來的、視窗上的名稱或發行者對得上，再按「是」（這一項是 Git；第 9、10 項也可能跳，名稱跟 PowerShell、GitHub 有關）。沒跳出來也正常。沒在裝東西卻跳出來，或名稱看不懂、對不上，就按「否」，再把剛才在做哪一步告訴網頁版 AI 或陳老師（這個視窗通常截不到圖）。

    可能跳出要你安裝「命令列開發者工具」的視窗，git 就在裡面，按「安裝」，等幾分鐘。

    完成判準：它回你一個 git 的版本號。安裝視窗如果要你輸入密碼或管理員帳號，自己在那個視窗輸入，不要貼給 AI；不知道是哪一組，就停下來求救。

  9. 9Windows 才要做：裝 PowerShell 7交給 AI 助手做

    Mac 不用做，直接打勾。

    Windows 內建的舊版 PowerShell 請 AI 寫入中文內容的檔案時，有時會存成 git 認不出的格式，之後就看不到改了哪一行。PowerShell 7 是新版的指令工具，裝了可以避開大部分這類問題。貼這句：

    我用的是 Windows。請幫我確認有沒有 PowerShell 7（程式名叫 pwsh）；沒有的話用 winget 或微軟官方網站幫我裝好，跟內建的舊版並存，不要移除舊的。要我做什麼請一步一步說。裝完如果找不到 pwsh，先檢查安裝位置，不要反覆重裝。最後實際用 pwsh 跑一次，把版本號給我看；之後這個對話要用 PowerShell 時，都用 pwsh。

    一樣可能跳出「是否允許這個 App 變更你的裝置」，名稱跟 PowerShell 有關、是你剛請 AI 裝的，再按「是」（判斷方式同第 8 項）。

    完成判準：AI 實際用 pwsh 跑過，回報一個 7 開頭的版本號（像 7.6.x 這樣）。

  10. 10GitHub 登入交給 AI 助手做

    它會裝一個叫 gh 的小程式，讓電腦記住你的 GitHub 登入。貼這句：

    請幫我裝 GitHub 的命令列工具 gh，然後登入我的 GitHub 帳號。請一步一步告訴我要做什麼。要我輸入的八碼和網址，請單獨貼在對話裡給我。最後告訴我登入的帳號名是什麼。

    安裝時一樣可能跳出「是否允許這個 App 變更你的裝置」，名稱跟 GitHub 有關、是你剛請 AI 裝的，再按「是」（判斷方式同第 8 項）。

    1. 它會給你一組八碼：八個英文字母和數字，中間一條短橫線，長得像 A1B2-C3D4（不是密碼）。先複製起來，大約 15 分鐘內有效。
    2. 瀏覽器打開 github.com/login/device。畫面如果先要你登入，用第 5 項的 GitHub 帳號登入；看到輸入框後，把八碼貼進去，按 Continue。
    3. 確認畫面上寫的是 GitHub CLI、右上角是你自己的帳號，再按 Authorize 授權。回到 AI 助手，它會說已登入。只輸入你自己電腦上剛出現的八碼；別人傳給你的不要輸入，你的也不要傳給別人。

    Mac 上它可能先裝另一個安裝工具（Homebrew），過程中會要你輸入電腦密碼，自己輸入就好。

    完成判準：它回報的帳號名就是你的 GitHub 帳號。

  11. 11Zotero：要寫論文的人再裝（選做）卡住問網頁版

    Zotero 是管理參考文獻的免費程式。到官方下載頁 zotero.org/download，下載程式並照畫面裝好；同一頁也有瀏覽器的 Zotero Connector，裝到你常用的瀏覽器。

    Connector 就是瀏覽器上的「存進 Zotero」按鈕。裝好後如果看不到 Zotero 圖示：Chrome 點右上角的拼圖圖示，按 Zotero 旁邊的圖釘；Edge 點右上角的拼圖圖示，選 Zotero 旁邊的「在工具列中顯示」（圖示可能是一隻眼睛）。

    用 Safari 的人不用另外裝 Connector，它已經包在 Zotero 裡：先打開 Zotero 一次，再到 Safari 的設定「延伸功能」打開就好。

    完成判準：Zotero 打得開；在期刊網頁按瀏覽器上的 Zotero 圖示，文獻會出現在 Zotero 裡（Zotero 要開著）。

  12. 12小試身手：讓它真的動手一次交給 AI 助手做

    第 8–10 項有新裝東西的話，先把 AI 助手的程式關掉、重新打開，再做這一項。新裝的工具，要重開後它才找得到。

    在第 6 項打開的 AI-workshop 裡，貼這句：

    請在這個資料夾裡建一個資料夾 warmup-check，裡面建一個 hello.txt，內容寫今天的日期和我的 GitHub 帳號名。然後把這個資料夾交給 git 存一版，版本說明寫「行前測試」；如果 git 要名字和信箱，名字用我的 GitHub 帳號名；信箱用 GitHub 提供的 noreply 信箱，請用 gh 查我的帳號數字 ID，組成「數字ID+帳號名@users.noreply.github.com」，不要用我的真實信箱，也不要用猜的。這一版只存在這台電腦，不要上傳到 GitHub。做完告訴我：warmup-check 的完整路徑、git 的版本、gh 登入的是哪個帳號，並把 git 最新一筆紀錄（git log -1）原樣貼給我看。除了這個新資料夾，其他都不要碰。

    舊帳號的 noreply 信箱格式可能不同，以 GitHub 網站「Settings → Emails」顯示的為準。

    然後照它說的位置，自己打開 hello.txt 看（按兩下會用記事本或文字編輯開）。AI 說做完，不等於做完；這也是當天要練的第一件事。

    完成判準四樣：hello.txt 真的在、內容對；它回報了 git 版本；回報的 gh 帳號是你的；它貼出的 git 紀錄裡看得到「行前測試」。
