六個會一直遇到的詞
書目管理（reference management）
保存作者、題名、期刊、年份等資料，寫作時再帶入引用。Zotero 是做這件事的軟體。
引用（citation）／參考文獻表（bibliography）
前者放在正文，指出這句話依據哪篇；後者在文末列完整出處。
DOI（Digital Object Identifier）
出版品的持久識別碼，例如本課練習的 10.1186/s12877-021-02075-3。不是每份出版品都有。
LaTeX
在純文字裡標示標題、引用與圖表，再交給排版程式產生 PDF 的寫作方式。
建置（build）
在本課範本中，一次執行分析、畫圖、檢查引用與排版的流程。不是 AI 宣布完成就算成功。
引用代號（citation key／cite key）
LaTeX 原稿用來指向某一筆書目的短名字，例如 Su2021；它不等於 DOI。

02 · 兩條路線都會用到

Zotero：先把一篇文獻收對

PDF 是你閱讀的全文；書目條目是作者、題名、期刊、年份等資訊；閱讀筆記則記錄你從原文看懂了什麼。這三件東西有關係，卻不是同一件事。先展開下面步驟，一次做一項。

Z1安裝 Zotero 與瀏覽器 Connector在哪裡：瀏覽器 → Zotero 官網 → 你的電腦
  1. 到 Zotero 官方下載頁，下載適合 Windows 或 Mac 的桌面版。它是免費軟體。
  2. Windows：開啟下載的安裝程式，依畫面完成。Mac：開啟 .dmg，將 Zotero 拖到「應用程式（Applications）」。
  3. 回同一下載頁，為你平常使用的瀏覽器安裝 Zotero Connector。這是瀏覽器的儲存按鈕，不能取代桌面版。
  4. 開啟 Zotero 桌面版；瀏覽器的擴充功能選單裡應找得到 Zotero Connector。介面文字可能隨語言與版本不同。

桌面有 Zotero 視窗，瀏覽器有 Connector。先做本機練習不需要設定雲端同步。

官方安裝說明。帳號用於同步等功能；文獻 PDF 是否同步到雲端，另依你的研究規範設定。

Z2建立本課專用的文獻集在哪裡：Zotero 左欄「我的文獻庫（My Library）」
  1. 在「我的文獻庫」按滑鼠右鍵，選「新增文獻集（New Collection）」。
  2. 命名為 工作坊練習，再點它，讓它成為目前選取的文獻集。

文獻集像播放清單：同一篇文獻可以放進不同文獻集，不必複製成好幾筆。先不要把整個既有文獻庫匯入範本。

左欄多出「工作坊練習」，目前中央可能還沒有條目。

03 · 先在熟悉的工具練一次

Word ＋ Zotero：插入引用，再產生文末書目

這一段使用 Windows 或 Mac 的 Word 桌面版，保持 Zotero 開著。瀏覽器裡的 Word 網頁版不支援這個引用外掛；若只有網頁版，先完成第 02 段與本頁的引用示範，再請老師協助確認桌面版授權。不需要裝 Better BibTeX，也不需要先學 LaTeX。

  1. 開新文件。在 Word 建立空白文件，另存為「工作坊引用練習.docx」。檢查上方是否有 Zotero 頁籤。
  2. 先寫一句自己的筆記。例如寫「這裡要說明該研究採用的訓練方式。」這是寫作位置示意；正式內容要回到原文確認後再寫。
  3. 插入引用。把游標放在句尾，選 Zotero → Add/Edit Citation。第一次若問引用格式，先選老師指定的格式；沒有指定時，練習可先選 APA。輸入作者姓氏、題名關鍵字或年份，選剛加入的文章，再按 Enter 完成。
  4. 產生文末書目。把游標移到文末空白處，自己加上「參考文獻」標題，再選 Add/Edit Bibliography。
  5. 修改與更新。要換引用，回正文的該引用用 Add/Edit Citation 修改；Zotero 書目資訊修正後，回 Word 按 Refresh。改格式則到 Document Preferences 選另一個樣式。
完成判準：正文有 Zotero 插入的引用，文末有對應條目；在 Document Preferences 換格式後，兩處會跟著更新。
Word 沒出現 Zotero 頁籤？

Zotero 的 Word 外掛通常隨桌面版一起安裝。先關閉 Word，在 Zotero 設定的「引用（Cite）→文書處理外掛（Word Processor Plugins）」檢查或重新安裝 Word 外掛，再重開 Word。名稱依版本與語言略有差異；仍失敗時依官方安裝與疑難排解處理。

不要直接手改 Zotero 產生的書目文字。

下一次更新可能覆蓋手改內容。請先改 Zotero 條目的資訊，再按 Refresh。Unlink Citations 會解除自動更新的連結；只在期刊要求、且已另存最終副本時考慮使用。

LaTeX、TeX、MiKTeX、MacTeX、Overleaf 是同一個東西嗎？
LaTeX 是原稿的寫法與文件系統；TeX 引擎執行排版。MiKTeX、TeX Live、MacTeX 是把引擎、套件與管理工具裝在電腦上的發行版；MacTeX 是 Mac 上常用的一套。Overleaf 則提供瀏覽器中的 LaTeX 編輯與編譯服務，可作為不在本機裝 TeX 的入門選項。
本課範本還會呼叫 Python 分析與 gnuplot 畫圖，只把 main.tex 上傳到 Overleaf，不等於整個 build 都能跑。本頁主線使用本機 AI 助手與完整資料夾；雲端工具涉及的資料傳送要另外確認。

07 · 有了自己的寫作題目再接
Zotero 怎麼把文獻交給 LaTeX？

      
Word 外掛直接從 Zotero 插引用；LaTeX 則常讀取一個書目文字檔 refs.bib。Better BibTeX 是 Zotero 的免費外掛，可以把選定文獻集匯出成這種檔案，並保持更新。

      
先練習匯出，不要覆蓋範本正在用的七筆書目。
本課 Zotero 練習文獻集可能只有一篇，範本原稿卻引用七篇。直接拿一篇覆蓋 source/refs/refs.bib，其餘引用就會找不到。先匯出到下方練習位置；開自己的新稿時，再請 AI 確認書目與正文引用如何一起切換。

      
接法 A：Better BibTeX 匯出

      
  1. 下載外掛。開 Better BibTeX 官方安裝頁，循它的連結下載 .xpi。這是 Zotero 外掛，不是瀏覽器外掛；Firefox 使用者依官方說明以另存連結下載。
  2. 裝進 Zotero。在 Zotero 選「工具（Tools）→外掛（Plugins）」，齒輪選單選「從檔案安裝外掛（Install Plugin From File）」，選剛下載的 .xpi，依畫面完成安裝與必要的重啟。
  3. 先由 AI 建好練習資料夾。在你的 ai-paper-kit 內準備 workspace/zotero-practice/。可說：「請只建立這個練習資料夾，不改 source 的書目與原稿。」
  4. 匯出文獻集。在 Zotero 對「工作坊練習」按右鍵 →「匯出文獻集（Export Collection）」。格式選 Better BibTeX，勾選 Keep updated。
  5. 選對位置。存到剛才的 workspace/zotero-practice/refs.bib。核對完整路徑，避免存成 refs.bib.txt，也不要選到原範本的書目檔。
  6. 請 AI 讀回核對。它應列出每筆的題名、年份、DOI 與 cite key。實際代號由你的匯出結果決定，不要假定一定是範例中的 Su2021。

研究資料使用條件：本機 AI 與 GitHub 要分別確認
  1. 去識別化：姓名、聯絡資訊、病歷號，以及組合後仍能認出人的資訊都要處理。
  2. 研究核准與同意範圍：允許每一家實際會處理資料的 AI 服務，並確認使用的帳號、資料分享與保留設定。
  3. 存放與雲端處理：若要放到 GitHub，資料管理計畫與機構規範必須允許；GitHub Actions 建置也會讀取上傳的資料。
  4. 研究儲存庫 的存取權：若使用 GitHub 保存自己的研究，設為 Private，並控管受邀成員；Private 本身不代表前面三項已符合。
