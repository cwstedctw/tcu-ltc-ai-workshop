老師們課前問的四件事（10/22 所長轉來），答案先寫在這裡：

1. 桌面版和網頁版怎麼同步？不用設定。用同一個帳號登入，一般對話、專案和設定就會跟著帳號走。只有一個例外：Codex 和 Claude 的 Code 在電腦資料夾裡做的事，紀錄通常只留在那台電腦。看第 01 段〈三扇門〉。

2. AI 讀 PDF，要不要先轉成 Markdown？一般不用：網頁版、桌面版的對話和專案，都能直接上傳 PDF。兩種情況才建議轉：① 掃描的 PDF（用滑鼠選不起來字），AI 可能讀錯，先問它「這份讀得到全文嗎」；② 要放進資料夾、讓 Codex 或 Claude 的 Code 反覆用的長文件。Markdown（.md）是純文字檔，記事本就打得開。轉法：在打開那個資料夾的 AI 助手裡貼這句（＿＿換成檔名）：

請把 material/＿＿.pdf 轉成 Markdown，存成同一個資料夾裡的同名 .md 檔；表格要保留成表格。轉完告訴我：用了什麼方法、有沒有讀不到或沒把握的地方（例如表格、數字、公式），列給我看。

10/23 用 Codex 實跑這句（拿第三部分的範例論文 PDF）：三張表轉成表格，220 個數字逐一比對都一致，兩張圖另存成圖檔。它可能要先裝轉檔的小工具，跳框時照第 2-6 段的判斷方式。轉完自己抽查幾個數字。

3. 「不知道就說不知道」「去 AI 味」，能不能設定一次就好？可以。寫在 ChatGPT 的「自訂指示」（2-3）和「給 Claude 的指示」（3-3），之後每一段新對話都會照著做；只跟某一件研究有關的，寫在專案指示（2-5、3-5）。2-3 那段已經寫了「沒有把握就說『我不確定』，不要編造文獻」。想去 AI 味，可以在那段後面自己加一行，例如：「5. 寫作時用自然的台灣學術中文，不要用『首先、其次、總而言之』這類套話，不要每段都條列，不要誇大的形容詞。」改完開一段新對話試試。對話拉得很長時，它還是可能忘，重要的事再提醒一次。

4. Claude 的 skills 怎麼跟其他 AI 連結，不用每次下 prompt？skill 是一個資料夾，裡面一份 SKILL.md，寫「什麼時候用、怎麼做」。Claude 和 ChatGPT 的 Codex 讀得懂同一種格式，AI 看到任務符合說明，會自己拿出來用，不用每次貼提示詞。放法：Claude 在設定裡先打開程式碼執行，再到「Customize → Skills」上傳 skill 資料夾的 ZIP 檔，Claude 的 Code 也讀得到；Codex 讀研究資料夾裡的 .agents/skills/（字樣與位置以你的畫面和官方說明為準：Claude、Codex）。第 05 段的 AGENTS.md 是同一個想法：規則寫成檔案一次，兩家都照著做；第二部分會實際做一次。

02・兩家各六步

設得好

先關訓練開關，再開始用

「設定」從哪裡打開：點畫面左下角你的頭像（Claude 是名字縮寫的圓圈），在跳出的選單裡點「設定」（以你的畫面為準）。下面的箭頭「→」，意思是「點開，再點下一個」。找不到某個選項，就截圖貼給網頁版 AI，問「這個設定在哪裡？」（截圖的方法在行前準備第 1 項）。

ChatGPT 做過行前準備的人，2-1 確認一下就好

  1. 2-1裝桌面版，用同一個帳號登入

    從官方下載頁 chatgpt.com/download 下載，照畫面裝好。不要用搜尋引擎找安裝檔，網路上有假的。

    用 Mac 的話，需要 macOS 14 以上（蘋果選單 → 關於這台 Mac，可以看版本）。

    用跟網頁 同一個帳號、同一種登入方式（Google、Apple 或 email）登入，不然可能變成兩個帳號。

    完成判準：在桌面版隨便打一句話，到網頁版重新整理，看得到那段對話；點兩邊左下角的頭像，看到的 email 一樣。不一樣的話，桌面版先登出，再用跟網頁版一樣的方式（Google、Apple 或 email）登入。

    裝不起來先用網頁版，2-2 到 2-5 的設定都存在帳號裡，桌面版裝好後自動套用。

  2. 2-2先決定：要不要讓對話拿去訓練模型

    「訓練」是指公司拿大家的對話，去教下一版的 AI。

    位置：設定 → 資料控管 → 改善模型以惠及所有人（英文 Improve the model for everyone）。字樣以畫面為準。

    做研究建議關掉，而且在開始聊之前就先關。

    • 自己註冊的帳號（免費、付費都一樣）：預設可能會拿對話去訓練，要自己關。用學校信箱自己註冊的，也算自己註冊的帳號。
    • 學校統一買的方案（方案名稱有 Business、Enterprise 或 Edu）：預設不拿。不確定自己是哪一種，就當作自己註冊的，關掉。
    • 關掉之後：新的對話不拿去訓練，你的對話紀錄照樣留著；在一台電腦關，每台都生效。
    • 有用 Codex 的人：Codex 的設定裡如果看得到「Include environments」這一項（跟你打開的資料夾內容能不能拿去訓練有關），也把它關掉。位置以你的畫面為準；找不到就截圖問網頁版 AI。
    完成判準：這個開關是關的，或者你清楚知道自己為什麼開著。

  3. 2-3寫自訂指示：讓它每次都知道你是誰

    位置：設定 → 個人化 → 自訂指示（英文 Custom instructions）。先確認「啟用自訂」是開的。按下面的「複製」，貼進「自訂指示」那一格，把「失智症照護與照顧者教育」改成你的研究主題，最後按「儲存」（格子和按鈕的名稱以你的畫面為準）。

    我是慈濟大學長期照護研究所的研究人員，研究主題是失智症照護與照顧者教育。請用繁體中文、台灣用語回答。
1. 引用文獻一定附 DOI 或網址；沒有把握就說「我不確定」，不要編造文獻。
2. 統計名詞第一次出現時，附上英文原文。
3. 先給結論，再說理由。
4. 如果我貼上的內容有受試者、病人、家屬或學生的真實個資（姓名、病歷號、身分證字號、電話、地址），先提醒我刪掉，不要繼續分析。已發表文獻的作者、教材或量表裡的虛構人物不算個資。

    第 1 條的 DOI 是每篇論文的固定編號（像身分證號碼），拿它就能找回那篇論文；怎麼用，見第 03 段的第三條線。

    第 4 條只是最後一道提醒：AI 看到的那一刻，資料已經送出去了。個資要在貼上之前就拿掉。

    完成判準：開新對話問「你知道我是做什麼研究的嗎？」，它答得出你的研究主題。答不出來：回去確認「啟用自訂」是開的、有按儲存，再開一個新對話試。

  4. 2-4看一眼記憶開關

    位置：設定 → 個人化 → 記憶，有「參照已儲存的記憶」和「參照聊天紀錄」兩個開關。「記憶」是指 ChatGPT 會記住你提過的事（例如你的研究主題），之後的對話自動用上。

    • 兩個開關的關係：關掉「參照已儲存的記憶」，「參照聊天紀錄」會跟著關。關掉「參照聊天紀錄」，它從過去對話記下的資訊會被刪掉。
    • 想刪掉某一條記憶：到「管理記憶」刪。只刪對話，記憶還在。
    • 只想問一次、不留紀錄：用「暫存對話」（開法以你的畫面為準）。開始前可以選要不要套用記憶和自訂指示。沒按儲存之前，不留紀錄、不建記憶、不拿去訓練；按了儲存，就變成一般對話。
    • 暫存對話也不能放個資：沒儲存的暫存對話，OpenAI 仍可能為了安全保留最多 30 天。
    完成判準：說得出自己這兩個開關現在是開還是關。

  5. 2-5開一個研究專案

    這裡的「專案」是 ChatGPT 一般對話裡的專案，用來把同一件研究的文獻和對話收在一起；跟行前準備第 6 項在 Codex 裡建的專案（打開 AI-workshop 資料夾）是兩回事。

    上傳前先確認：計畫書若有審查中、合作單位要保密、還沒公開的內容，先確認可以上傳；拿不準，今天就先只放已經發表的文獻。

    左側欄 新專案，取名後上傳計畫書和幾篇文獻。專案指示在專案名稱旁邊的 ⋯（三個點）→ 專案設定（位置以你的畫面為準）。它只用在這個專案裡；跟 2-3 的自訂指示說法不一樣時，以專案指示為準。把下面這段貼進去，第一句換成你自己的計畫名稱，再按儲存：

    這個專案是國科會失智症虛擬病人計畫。回答時只根據專案裡的檔案；檔案裡找不到的，直接說找不到，不要用一般知識補。引用時標出是哪一個檔案、哪一頁或哪一段；檔案裡沒有 DOI 或網址的文獻，寫「檔案未提供」，不要自己上網補。

    每個專案能放的檔案數：免費帳號 5 個，付費的 Go、Plus 方案 25 個。

    完成判準：在專案裡問一個從你放的檔案查得到的問題（例如「計畫書的第二個研究目的是什麼？」），再打開原文，確認答案對得上。

  6. 2-6認識 Codex：會動手做事的那一面

    桌面版左上角可以切換 ChatGPT 和 Codex。Codex 會打開你指定的資料夾（怎麼打開，照行前準備第 6 項），在裡面建檔、整理資料、做表格。練習用的資料夾只放假資料或公開資料。

    輸入框下方有一顆權限按鈕（按鈕上顯示的是目前的設定，選好「要求核准」後是手掌圖示），點開選 要求核准（英文介面叫 Ask for approval）：在你打開的資料夾裡，它會直接建檔、改檔、跑程式；要動資料夾以外的檔案、上網或裝東西，才會先問你。不要選「完整存取權」（Full access），也先別選「代我核准」（Approve for me，由系統判斷要不要問）。

    所以要靠做完之後自己看結果：它說改了哪些檔、做出來的東西對不對。重要的事（例如裝東西、刪檔），可以先跟它說「先告訴我你要做什麼，等我說好再做」。

    跳出要你核准的框時：看得懂、是你剛請它做的事（例如你請它裝一個工具，框裡寫的就是在裝那個工具），就按同意（只同意這一次）。看不懂，就按拒絕，拒絕不會弄壞東西；再問它「這一步要做什麼、為什麼要做」，或截圖問網頁版。

    免費帳號也能用 Codex，但用量（額度）有限，做到一半可能要停下來等。價格以 chatgpt.com/pricing 為準。

    完成判準：左上角顯示 Codex，權限選單顯示「要求核准」（或 Ask for approval）。今天先認識，第二部分會實際用它。

    • 只想讓某一次對話不用記憶：送出第一句之前，在輸入框的「＋」選單把記憶關掉。
    • 敏感主題：健康、信仰這類主題，記憶功能預設不會記下來；但對話本身照樣送出、照樣保存，個資一樣不能貼。
    • 無痕對話：在一般對話（不在專案裡）的畫面右上角，點小幽靈圖示開啟。它不拿去訓練，但仍會保留 30 天；專案裡沒有這個功能。它跟 ChatGPT 的「暫存對話」差不多。
    完成判準：說得出自己的記憶現在是開還是關。

  5. 3-5開一個研究專案

    左側欄 專案 → 新增專案，上傳文獻到專案的知識區，再按「設定專案指示」，貼上下面這段，第一句換成你自己的計畫名稱：

    這個專案是國科會失智症虛擬病人計畫。回答時只根據專案裡的檔案；檔案裡找不到的，直接說找不到，不要用一般知識補。引用時標出是哪一個檔案、哪一頁或哪一段；檔案裡沒有 DOI 或網址的文獻，寫「檔案未提供」，不要自己上網補。

    記憶開著時，同一個專案裡的對話會互相記得。但重要的資料不要靠它記：要 Claude 每次都讀得到的，就上傳成檔案放進知識區。審查中或要保密的內容，先確認可以上傳。免費帳號最多 5 個專案。

    完成判準：挑一篇你放進去的文獻，問「＿＿這篇的主要結論是什麼？」（＿＿換成那篇的檔名），再打開那篇原文，確認答案在裡面找得到。

  6. 3-6請它做一頁互動網頁

    Claude 可以把整理好的內容做成一頁可以點的網頁（中文介面叫「成品」，英文 Artifacts）。打開 3-5 建好的專案，在專案裡開一個新對話（以你的畫面為準），貼上這句：

    請把我們專案裡的文獻整理成一頁互動網頁：上面一張比較表，可以依「研究設計」篩選；點一篇可以展開看研究對象、介入方式和主要結果。每一篇附檔案裡有的 DOI 連結或網址，兩者都沒有就寫「檔案未提供」，不要自己上網補。內容只能用專案裡的檔案，找不到的格子寫「檔案未提」；只有摘要、讀不到全文的文獻，在表格下方列出來。

    做不出網頁的話，到「設定 → 功能」確認「成品」和「雲端程式碼執行與檔案建立」兩個開關都是開的。

    做好的表裡，寫「檔案未提供」＝檔案裡找不到這篇的 DOI 或網址；寫「檔案未提」＝那一格的內容在檔案裡找不到。

    今天練習做的頁面先不要分享。真的要分享時，看清楚分享範圍（選項依方案不同）：「任何有連結的人」表示拿到連結的人都打得開、也能再轉傳，等於公開。未發表資料、受試者資料一律不放。

    完成判準：對話旁邊打開一頁可以點的網頁（沒看到，就點回覆裡那張小卡片；以你的畫面為準）。上面有一張可以依「研究設計」篩選的比較表，點一篇會展開；每篇文獻都對得上專案檔案。
Claude 做完勾一勾（6 項全勾，解鎖技能卡 03）
03・三條線

守得住

設定再好，這三條線都要自己守

一

確認允許、去識別化，才上傳

原則上只上傳彙總結果（例如平均數、百分比）；樣本很小或個案很少見時，彙總結果也可能認得出是誰。

逐字稿這類一個人一份的資料，下面三件事都做到，才可以上傳：

  1. 已經去識別化（下面列的都拿掉）。
  2. IRB（研究倫理審查）核准的計畫書和同意書，都允許用這個 AI 工具；不允許，就先向 IRB 申請變更。
  3. 學校的規定也允許。

有一件不確定，就先問 IRB；問不到答案，就不上傳。要拿掉的不只姓名：病歷號、身分證字號、電話、地址、出生或就診日期、機構和病房名稱、村里地名、家屬姓名、少見的病史或職業、照片、錄音。

二

看清楚資料條款

個人帳號不論免費或付費，預設都可能拿對話改進模型，要自己關；學校或機構買的 ChatGPT Business／Enterprise／Edu、Claude Team／Enterprise 預設不拿。關掉訓練，不等於對方不存資料。研究用的對話不要按讚或倒讚。IRB 計畫書要寫明用哪一家工具、資料存在哪裡（存在那家公司的雲端；保存多久，見頁尾的官方說明）；拿不準怎麼寫，就問 IRB。

三

AI 給的文獻，每一筆都回查

AI 可能編出看起來很真的文獻，也可能把真的論文講錯，所以每一筆都用 DOI 打開來看。DOI 是每篇論文的固定編號（像身分證號碼）。在瀏覽器網址列打 https://doi.org/，後面接上 DOI，按 Enter，就會開到那篇論文的頁面。例如 https://doi.org/10.1186/s12877-021-02075-3。

開到之後，對一下題目和作者；再打開摘要或原文，確認 AI 引的那句話原文真的有寫。打不開、或跳出找不到的頁面，這筆先不要用：可能是抄錯，也可能是 AI 編的。沒有 DOI 的中文文獻，改到華藝、國圖期刊文獻資訊網或 Google Scholar 查。

三條線說得出來，也知道為什麼。

05・接到第二部分

接得上

兩個 AI 共用一個資料夾，GitHub 帶著它跨電腦

各家聊天的記憶是分開的：ChatGPT 記得的事，Claude 不知道。要讓它們分享資訊，就讓它們打開同一個資料夾：一個 AI 把結果寫成檔案，另一個打開同一個資料夾就讀得到。

下面資料夾裡的 .md 檔是純文字檔，用記事本（Mac 是「文字編輯」）就打得開。

Codex
ChatGPT 桌面版裡會動手的那一面
開工先讀 AGENTS.md
研究計畫資料夾
  • AGENTS.md 團隊規則（兩家共用這一份）
  • CLAUDE.md 只有一行「@AGENTS.md」，意思是「去讀 AGENTS.md」
  • material 老師的材料（AI 只讀、不寫）
  • workspace 工作區，裡面有：
    • inbox 交辦的紙條
    • outbox 做好的成品，每一版都留著
Claude
Claude 桌面版裡會動手的 Code
開工先讀 CLAUDE.md，再轉去讀 AGENTS.md

Codex 把成品存進 outbox，Claude 打開同一個資料夾就看得到；反過來也一樣。

要在不同電腦接著做，就靠 GitHub。GitHub 是放資料夾備份、讓不同電腦拿到同一份的網站（行前準備第 5 項註冊過）。放在 GitHub 上的那份資料夾，叫做「儲存庫」。

辦公室電腦⇄GitHub（Private）⇄家裡電腦筆電

  1. 用會打開資料夾的那一面。ChatGPT 桌面版的 Codex、Claude 桌面版的 Code。網頁上的一般對話看不到你電腦裡的資料夾。權限照行前準備第 7 項：Codex 選「要求核准」（Ask for approval；在打開的資料夾裡會直接動手，見 2-6）；Claude 的 Code 選 Manual（改檔、跑指令前都會先問你）。Claude 的 Code 還要在環境選單選「本機（Local）」，意思是在你這台電腦上做（行前準備第 6 項）。

    要付費：Claude 的 Code 要 Pro 以上。只用免費帳號的人，這一段用 Codex 做。

  2. 規則寫成檔案。Codex 開工先讀 AGENTS.md；Claude 開工先讀 CLAUDE.md，而 CLAUDE.md 裡只有一行「@AGENTS.md」，意思是「去讀 AGENTS.md」。所以兩家最後讀的是同一份規則；要改規則，只改 AGENTS.md 一個地方。規則長什麼樣子？例如第二部分的範本裡寫著：老師的材料，AI 只讀、不寫。

  3. 開工先拉、做完就推。「拉」是把 GitHub 上的新版抓到這台電腦，「推」是把這台電腦的改動送上 GitHub。不用背指令：第二部分會一步一步帶你建好，開工、收工也各有一句話貼給 AI。

    建儲存庫時一定選 Private（私人），建好後確認頁面上寫的是 Private。Private 只是別人看不到，資料還是上傳到 GitHub 了：受試者資料，還有密碼、備援碼這類登入用的東西，都不要放進這個資料夾。GitHub 會留下每一個舊版本，就算後來刪掉，舊版本裡還找得到，所以一開始就不要放。

  4. 同一時間只讓一個 AI 改檔。兩個 AI 接力時，一個在改，另一個先只看、只檢查，免得同一個檔案被兩邊改亂。

第二部分會用範本資料夾做一件研究工作：只用一家 AI 也做得完，兩家都能用的人再練習接力。
