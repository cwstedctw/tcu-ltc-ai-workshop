01・一個數字的旅程

追得到

論文裡的 37.04，是從哪裡來的

用 Word 寫論文，數字是從統計軟體抄進去的。這條流程裡，論文沒有一個結果數字是手打的：程式算好、取一個名字（代號），論文裡只寫代號，排版時才換成數字。下面跟著「介入組第 12 週的知識分數平均」走一次。

資料：
  1. 1
    source/data/study_data.csv原料

    一列一個人。dkas_t1 是第 12 週的知識分數（0–50）。程式只讀這個檔，不改它。

    id group dkas_t1 I001 intervention 37 I002 intervention 44 I003 intervention 43 … I048 intervention 12 …（介入組共 70 人）
  2. 2
    source/scripts/analyze.py原料（程式）

    分析程式算介入組 dkas_t1 的平均，照 SPSS、Excel 的方式四捨五入到小數兩位，再給這個數字取名叫 DKASIntTOneMean（DKAS、介入組 Int、第 12 週 TOne、平均 Mean）。

    # 排除名單：老師決定，寫在程式最上面 EXCLUDE_IDS = [] # 每個量表、每一組、每個時間點，都算平均並取名 macros[f"{scale}{gk}{tname}Mean"] = fmt(s.mean(), 2)
  3. 3
    output/numbers.tex成品

    程式把每個數字寫成一行：代號＝數字。這個檔每次 build 都重做，不要手改。

    \newcommand{\NTotal}{140} \newcommand{\DKASIntTOneMean}{37.04} \newcommand{\DKASTOneD}{0.92}
  4. 4
    source/paper/main.tex原料（論文本文）

    論文本文裡寫的是代號，不是數字。換資料時，這一句一個字都不用改。

    At week 12, DKAS scores were \DKASIntTOneMean{} in the intervention group and \DKASCtlTOneMean{} in the control group (\DKASTOnePstat{})…
  5. 5
    output/main.pdf成品

    排版時，LaTeX 把代號換成 numbers.tex 裡的數字。你看到的論文長這樣：

    At week 12, DKAS scores were 37.04 in the intervention group and 30.43 in the control group (p < 0.001)…

按上面的「排除 I048」，看哪些數字一起變

  • 現在用的是全部 140 人，數字跟論文對得上。

數字會自動更新，句子的解讀不會。例如排除一個人之後，Discussion 裡「結果跟論文對得上」那句就不再成立：數字變了，用到它的句子要你重讀一次。

02・一張圖的旅程

畫得出

程式做小表，gnuplot 照表畫圖

圖也一樣不是手畫的。分析程式先把畫圖要的數字整理成一張小表，gnuplot 腳本讀這張表、照腳本的指示畫出來。資料變了，表跟著變，圖也跟著重畫。

① 小表 output/figdata/fig1_dkas.csv（Excel 打得開）

timeint_meanint_sdctl_meanctl_sd
0（前測）26.6866.71925.5438.140
1（第 12 週）37.0437.93030.4296.439
2（第 24 週）36.2005.55029.9437.539

int＝介入組、ctl＝對照組；mean＝平均、sd＝標準差。這張小表跟著第 01 段的「資料」切換一起變。

② 腳本 source/gnuplot/fig1_outcomes.gp：每一行在做什麼

set terminal cairolatex pdf size 12cm,6cm畫成 12 公分寬（論文版面的寬度）。圖上的字交給 LaTeX 排，跟內文同一套字型；放大也不會糊。
set output 'figures/fig1.tex'畫好存到 output/figures/。Word 版另外存一份 PNG。
set datafile separator comma小表是 CSV，用逗號分欄。
set style line 1 lc rgb '#0072B2' lw 2 pt 7介入組：藍色實線、圓點。藍和橘是色盲也分得出來的配色。
set xtics ('0' 0, '12' 1, '24' 2)橫軸的三個點標成第 0、12、24 週。
set autoscale y縱軸範圍跟著資料走。換資料不會把點切掉。
set multiplot layout 1,3一張圖裡並排三張小圖：DKAS、ADQ、SCIDS。
plot 'figdata/fig1_dkas.csv' every ::1 using ($1-0.04):2:3 with yerrorlines ls 1讀小表，跳過第一列欄名；第 1 欄當橫軸，第 2 欄（平均）當縱軸，第 3 欄（標準差）畫成誤差線。
'' every ::1 using ($1+0.04):4:5 with yerrorlines ls 2同一張表的第 4、5 欄是對照組；往右挪一點，兩組的誤差線才不會疊在一起。

這些你不用背，也不用自己寫：跟 AI 說要什麼圖，它會改腳本。看得懂每一行在做什麼，就能檢查它改得對不對。

③ 畫出來的圖 output/figures/fig1

畫法：

同一張小表，用折線畫。藍色實線是介入組，橘色虛線是對照組；誤差線是標準差。

為什麼要分開：原料是你的研究，要好好保存；成品隨時能重做，所以不推上 GitHub，也不怕被改壞。真的研究資料能不能交給 AI、能不能推上 GitHub，先照主頁第 07 段〈研究倫理〉的四個條件確認；Private 本身不代表可以上傳。核對數字時，用 Excel 打開 output/tables 資料夾裡的 .csv 檔就好；看完關掉時按「不要儲存」。

04・六個練習

動手做

你只跟 AI 說話，大約 30 分鐘

開始前（回家自己做也照這張）
  1. 範本資料夾已經在電腦裡（資料夾名稱 ai-paper-kit；範本從哪裡拿，當天講師會說）。還沒有的話，照第三部分主頁第 04 段第 1 步。
  2. 工具裝好了：照主頁第 03 段那句話請 AI 幫你裝，AI 列出四個版本號、沒有「找不到」才算。
  3. 打開「看得到你電腦資料夾」的那一面 AI：ChatGPT 桌面版裡的 Codex，或 Claude 桌面版裡的 Code（第一部分設定課教過；網頁上的一般對話看不到你電腦裡的資料夾）。權限照第一部分設定：Codex 選「要求核准」，Claude 的 Code 選 Manual。
  4. 範本是用 ZIP 下載解壓縮的：報到之前先跟 AI 說「請先檢查這台電腦有沒有 git；有的話幫這個資料夾存一版（commit），存好告訴我」。存好了才做下面的報到。用 git 下載（clone）的不用做這步。
AI 問你「可不可以」的時候　權限設成「要求核准」，AI 每次要跑程式或改檔都會先跳出確認（常是英文）。跑 build、改 analyze.py、改 .gp、改 main.tex：這些是練習本來就要做的，按同意。要刪檔、裝東西、動 source/data/、上網：先別按，問它「這一步在做什麼」。一個練習可能會問好幾次，正常。

    研究設計的限制，它先講

    研究構想是兩家機構、以機構為單位分派：一家當介入組，一家當對照組，機構本身的差別跟組別分不開。所長的原論文在限制段就談到兩家機構的差異；我們給 AI 的研究構想故意沒抄進這一點，AI 第 2 步還是自己提出來，建議寫進研究限制、請老師問統計顧問；第 8 步清單裡「統計方法跟研究設計相符」那一條也沒過。

    結果跟原論文不一樣，它說得出原因

    GEE 的結果不會跟所長論文一樣：GEE 要用到同一個人三次分數之間的關係，練習資料裡這個關係是假設的（0.5），不是真的資料。AI 在第 2 步就說了，論文裡也寫明。

    寫得比摘要多，它自己逐句對才抓到

    第 6 步的初稿有 5 句寫得比文獻摘要多，犯了三種錯：替「上面引用的研究」做的總結寫錯了；把作者的結論寫成受訪者說的話；寫了一句沒有引用、聽起來像結論的轉折句。這種錯 build 完全抓不到，是 AI 逐句對摘要才改掉的。你抽查時，也是找這三種。

    AI 使用聲明，差點替你寫了還沒做的事

    範例論文的聲明寫著「每篇引用都對過 DOI」「作者看過、改過」。第 7 步 AI 發現，照抄就等於替老師寫了還沒做的事，所以拆成「AI 做了什麼」（真的做過的）和一處紅字「老師要確認的」。

    模擬之後我們改了什麼

    • 研究資料不再跟著複製進 examples/。模擬時，開新論文和第 9 步都會把 source/data/ 的資料檔一起複製進 examples/；換成真的研究資料，就可能跟著推上 GitHub。現在收進 examples/ 時只留欄位說明，資料檔不複製。
    • Fisher 精確檢定改成完整列舉。SciPy 碰到超過 2×2 的表，預設用亂數模擬，每次 build 的 p 值都會差一點，build 也抓不到；現在範本改成把所有可能的分法一個一個算，每次結果都一樣。
    • new_paper.py --restore 是「複製」回來，不是「搬」回來。跑完之後 examples/ 裡那份還在，不需要的話再自己刪。
