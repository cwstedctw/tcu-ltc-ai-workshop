沒有 ChatGPT 付費方案：用工作坊的 API 金鑰登入 Codex

這一頁給沒有 ChatGPT 付費方案、或平常只用 Claude 的老師。當天第二、三部分要用 ChatGPT 桌面版裡的 Codex 動手做；費用由工作坊統一支付，你不用買方案。做法是：陳老師邀請你加入工作坊，你自己建一把「API 金鑰」，用它登入桌面版。大約 15 分鐘，照下面 6 步做。

00・開始之前

先知道

誰要做、金鑰是什麼、能用什麼

  • 誰要做這一頁：沒有 ChatGPT 付費方案的人，包括只有免費 ChatGPT 帳號、只用 Claude、或完全沒有 ChatGPT 帳號的人。已經有 ChatGPT 付費方案的人不用做，照原本的帳號用就好。
  • API 金鑰（API key）是什麼：一長串以 sk- 開頭的英數字，像一張「工作坊付費的通行證」。誰拿到它，誰就能花工作坊的錢，所以它只會出現在兩個地方：建立它的那個網頁，和 ChatGPT 桌面版的登入框。不要貼進任何對話框（包括 AI）、LINE、email，不要截圖、不要存成文字檔，也不要借給別人用。
  • 登入後能用的是 Codex（會打開資料夾、動手做事的那一面），這就是當天要用的。用金鑰登入時，ChatGPT 的一般聊天和雲端功能可能不能用（以你的畫面為準）；要聊天，用瀏覽器開 chatgpt.com 或 claude.ai。
  • 你還是需要一個 OpenAI 帳號（免費，跟 chatgpt.com 是同一套帳號），用來接受邀請、建自己的金鑰。沒有的話，第 2 步會順便註冊；可能要收信驗證或手機驗證，手機請帶在身上。
  • 只用虛構或公開的資料練習。不要輸入病歷、照護個案、姓名、聯絡方式或學生資料。
  • 這一頁的勾選只存在你這台電腦的這個瀏覽器裡，不會傳給任何人。
01・六個步驟

登得進

邀請 → 加入 → 建金鑰 → 登入 → 試一次 → 下課收尾

已完成 0 / 6

  1. 1把你的 email 給陳老師你自己做

    照現場的說明，把你要拿來登入 OpenAI 的 email 給陳老師。已經有 ChatGPT 免費帳號的人，給那個帳號的 email；用 Google 或 Apple 登入 ChatGPT 的人，給那個 Google／Apple 帳號的 email；完全沒有帳號的人，給一個你在這台筆電上收得到信的 email。

    陳老師會用這個 email 寄邀請，把你加進工作坊的「組織」和專案 tzuchi-workshop-20261028（專案就是工作坊統一付費的那個帳本）。加入之後，你看不到別人的對話，別人也看不到你的。

    完成判準：陳老師說邀請寄出了。

  2. 2收邀請信，加入工作坊你自己做・卡住舉手

    在這台筆電上用瀏覽器打開剛才那個 email 的信箱，不要用手機收信、按按鈕：等一下金鑰要在這台筆電上貼進桌面版，金鑰不能用 LINE 或 email 傳過來。找 OpenAI 寄來的邀請信（幾分鐘內會到；找不到就看垃圾郵件匣）。按信裡接受邀請的按鈕（按鈕字樣以你的畫面為準，可能是英文 Accept invite 或 Join）。

    • 已經有 OpenAI 帳號（用過 ChatGPT）：用原本同一種方式登入（Google、Apple 或 email），不然可能變成兩個帳號。
    • 還沒有帳號：照畫面註冊，免費。畫面要你選方案或付款時，不要付，先舉手問。

    只按信裡的按鈕。按之前看一眼網址列，要是 openai.com 結尾的網址；長得像邀請、但網址怪怪的，先舉手。

    登入後會到 platform.openai.com（OpenAI 給開發者用的後台，跟 chatgpt.com 同一個帳號）。看畫面左上角：點開組織選單，選到陳老師的組織（名稱現場會寫在白板上；找不到就舉手），專案選 tzuchi-workshop-20261028。

    你自己的組織或專案（常叫 Personal 或 Default project）也會出現在清單裡。不要在那裡建金鑰：在那裡建，就會用你自己的錢付費。

    完成判準：platform.openai.com 左上角顯示的專案是 tzuchi-workshop-20261028。

  3. 3建你自己的 API 金鑰你自己做・卡住舉手

    1. 瀏覽器網址列打 platform.openai.com/api-keys，按 Enter。先再看一次左上角：專案還是 tzuchi-workshop-20261028。
    2. 按 Create new secret key（建立新的金鑰）。
    3. 名稱（Name）打你的座位號，例如 ws-12。不要打姓名：名稱陳老師後台看得到，用座位號就好。
    4. 擁有者選 You（你自己）；專案（Project）選 tzuchi-workshop-20261028；權限（Permissions）選 All。按 Create secret key。
    5. 畫面出現一長串 sk- 開頭的字：這是唯一一次看得到完整的金鑰。按旁邊的 Copy（複製），這個網頁先不要關，直接做第 4 步。

    按鈕字樣以你的畫面為準。Create 按鈕是灰的、按不下去：舉手請陳老師看一下你的權限，不要借別人的金鑰。不小心關掉、沒複製到：把那把刪掉（第 6 步的做法），重建一把就好。

    完成判準：金鑰清單裡有你剛取的名字（例如 ws-12），而且你已經按了 Copy。

  4. 4ChatGPT 桌面版改用金鑰登入你自己做・卡住舉手

    還沒裝 ChatGPT 桌面版的人，先到 chatgpt.com/download 下載、照畫面裝好（跟行前準備第 2 項一樣）。

    1. 打開 ChatGPT 桌面版。已經用自己的帳號登入的人：先點左下角的頭像（個人選單）→ Log out（登出），回到登入畫面。
    2. 在登入畫面選 Sign in another way（用其他方式登入）。
    3. 在金鑰的欄位按 Ctrl＋V（Mac：Command＋V）貼上剛才複製的金鑰，按 Continue。
    4. 再點一次左下角的個人選單，看得到「用 API key 登入」之類的字樣，就是登入成功。

    找不到 Sign in another way：先確認真的登出了、開的是桌面版（不是瀏覽器的 chatgpt.com），再舉手。不能把金鑰貼進對話框代替登入，那樣金鑰會被當成一般訊息送出去。

    登入成功後，把金鑰從剪貼簿趕走：回到第 3 步那個網頁，按 Done 關掉金鑰視窗，再隨便複製一個字（例如這一頁的標題），把剪貼簿裡的金鑰蓋掉。

    Windows 如果開過「剪貼簿歷程記錄」（按 Win＋V 會跳出一串之前複製過的東西），在那個清單裡找到 sk- 開頭那一筆，按旁邊的「⋯」→ 刪除。

    完成判準：桌面版個人選單顯示是用 API key 登入；剪貼簿裡已經不是金鑰。

  5. 5切到 Codex，試一次AI 助手替你做

    1. 桌面版左上角切到 Codex，照行前準備第 6 項打開練習資料夾 AI-workshop（還沒建的人，照行前準備第 6 項現在建）。
    2. 照行前準備第 7 項，點輸入框下方的權限按鈕，選 要求核准（英文介面 Ask for approval）。不要選「完整存取權」（Full access），也不要選「代我核准」（Approve for me）。
    3. 貼下面這句，按 Enter 送出：
    請在目前這個資料夾建立 workshop-test.txt，內容只有「慈濟工作坊測試成功」。完成後告訴我檔案的完整路徑。

    在練習資料夾裡建檔，Codex 通常會直接建好、不會跳框（行前準備第 7 項說的：在你打開的資料夾裡，它會直接建檔）。如果跳出要你核准的框：看得懂、是你剛請它做的事（框裡看得到 workshop-test.txt），就按同意（只同意這一次）。看不懂，就按拒絕，拒絕不會弄壞東西；再問它「這一步要做什麼、為什麼要做」，或截圖問網頁版。

    然後自己去看：AI 說做完，不等於做完。用檔案總管（Mac：Finder）照它給的路徑打開 workshop-test.txt，看內容對不對。

    完成判準：你自己打開 workshop-test.txt，內容一字不差是「慈濟工作坊測試成功」。

  6. 6下課前收尾：刪金鑰、登出你自己做

    工作坊結束、陳老師說可以收的時候再做（做完 Codex 就不能用了）。登出不等於刪掉金鑰，兩件都要做：

    1. 刪金鑰：瀏覽器打開 platform.openai.com/api-keys，先看左上角的專案還是 tzuchi-workshop-20261028（被切回 Personal 就看不到你的金鑰，不代表已經刪了），找到你取的名字（例如 ws-12），按那一列最右邊的「⋯」或垃圾桶 → Revoke key（撤銷）→ 再確認一次。
    2. 登出桌面版：個人選單 → Log out。要回到自己的 ChatGPT 帳號，就在登入畫面用原本的方式登入。
    3. 用學校或別人的電腦的話，連瀏覽器裡的 platform.openai.com 也登出。

    練習做的檔案都在你的 AI-workshop 資料夾裡，刪金鑰、登出都不會刪到它們。之後想繼續用 Codex，可以買 ChatGPT 方案，或在自己的 OpenAI 組織建金鑰、自己付費。

    完成判準：platform.openai.com/api-keys 的清單裡，你那把金鑰不見了（或標示已撤銷）；桌面版回到登入畫面。
